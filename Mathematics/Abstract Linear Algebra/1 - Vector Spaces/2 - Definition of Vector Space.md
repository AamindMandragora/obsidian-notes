We will use the properties of $\mathbb{F}^n$ to define the vector space: addition is commutative, associative, has an identity and inverses, scalar multiplication is associative with an identity, and the two operations satisfy distributivity.

We will define a vector space to be a set $V$ with an addition and a scalar multiplication on $V$ as follows: An **addition** on a set $V$ is a function that assigns an element $u+v\in V$to each pair of elements $u, v$. A **scalar multiplication** on a set $V$ is a function that assigns an element $\lambda v\in V$ to each $\lambda\in\mathbb{F}$ and each $v$. Elements of a vector space are called **vectors** or **points**. 

Scalar multiplication depends on our choice of $\mathbb{F}$, so we'll often say that $V$ is a vector space **over** $\mathbb{F}$. Vector spaces over the real and complex numbers are called real and complex vector spaces, respectively.

If $S$ is a set, then $\mathbb{F}^S$ denotes the set of functions from $S$ to $\mathbb{F}$. If we define $f+g\in\mathbb{F}^S=(f+x)(x)=f(x)+g(x)$ and $\lambda f\in\mathbb{F}^S=(\lambda f)(x)=\lambda f(x)$, then $\mathbb{F}^S$ is a vector space where every vector is a function.

It turns out that vector spaces have unique identities and inverses, which helps us prove that $0v=0$ for all $v\in V$, $(-1)v=-v$ for all $v\in V$, and $a0=0$ for all $a\in\mathbb{F}$.
