# Linear Combinations and Span

A sum of scalar multiples of the vectors in a list is called a **linear combination** of the list, and takes the form $\sum a_kv_k$ for $a_k\in\mathbb{F}$ and $v_k\in V$. The set of all linear combinations of a list of vectors in $V$ is called the **span** of the list. The span of the empty list is $\set{0}$.

The span of a list of vectors in $V$ is the smallest subspace of $V$ containing all vectors in the list, and if the span of the list equals $V$, then the list **spans** $V$. A vector space is called **finite-dimensional** if there's a list of vectors that spans it (since every list has finite length). This means that $\mathbb{F}^n$ is a finite-dimensional vector space for every positive integer $n$.

Recall that a function $p: \mathbb{F}\to\mathbb{F}$ is called a polynomial with coefficients in $\mathbb{F}$ if there exist $a_1,\ldots,a_m\in\mathbb{F}$ such that $p(z)=a_0+a_1z+a_2z^2+\cdots+a_mz^m$. $\mathcal P(\mathbb F)$ is the set of all polynomials with coefficients in $\mathbb{F}$, and is a vector space over $\mathbb F$. This makes it a subspace of $\mathbb F^{\mathbb F}$. The coefficients of a polynomial are uniquely determined by the polynomial, which means the degree of a polynomial can simply be thought of as the degree of the largest term in the minimal representation of that polynomial. The degree of $0$ is $-\infty$. For a nonnegative $m$, $\mathcal P_m(\mathbb F)$ is the subspace of all polynomials with coefficients in the field and degree at most $m$.
# Linear Independence

If we have a list of vectors such that $v\in V$ is in the span of that list, then there's a set of coefficients $a_k$ such that $\sum a_kv_k=v$. If there exists another, distinct set of coefficients $c_k$ such that $\sum c_kv_k = v$, then we can subtract the two equations to write $0$ as a linear combination of the list. We define **linear independence** to refer to a list of vectors where the only way to write $0$ as a linear combination of them is for all the coefficients to equal $0$. This also means that a linearly independent list has a unique linear combination for each vector in the span. If vectors are removed from a linearly independent list, then the list is still independent.

If a list isn't linearly independent, it's linearly dependent. This means that every vector in the span has more than one linear combination representation, including the vectors in the list. Then, there must exist some $v_k$ that's in the span of the list $v_1,\ldots,v_{k-1}$. If we then remove $v_k$ from the original list, the span is unchanged.

If we have a linearly independent list $u_1,\ldots,u_m$, and a spanning list $w_1,\ldots,w_n$, then we can prove $m\leq n$ by considering the list $u_1,w_1,\ldots,w_n$. Since the $w$ list spans the space, that list is linearly dependent, which means we'll be able to remove one of the $w$ vectors (as the $u$ vectors are independent), to give us a list of length $n$. We can continue prepending the list by $u_k$, making it linearly dependent, and removing one of the $w$ vectors which is guaranteed to exist as the $u$ vectors are independent. After step $m$, we have added all the $u$'s and the process stops, meaning there are at least as many $w$'s as $u$'s.

Every subspace $U$ of a finite-dimensional vector space $V$ is finite-dimensional as we can keep choosing linearly independent $u_k$ to span $U$, and the previous result guarantees we can't choose more $u$ than necessary to span $V$ while keeping linear independence.
