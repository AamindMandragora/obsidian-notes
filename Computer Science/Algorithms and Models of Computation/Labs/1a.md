1. Prove that $|w| = |w^R|$ for every string $w$.

Let $w$ be an arbitrary string. Assume $|x|=|x^R|$ for every string $x$ such that $|x|<|w|$. There are two cases to consider:

If $w=\epsilon$, then $w^R=\epsilon=w$ by definition of $^R$ and $|\epsilon|=|\epsilon|$.

If $w=ax$ for some symbol $a$ and some string $x$, then $w^R=x^R\bullet a$ by definition of $^R$. $|ax|=|a|+|x|$ and $|x^R\circ a|=|x^R|+|a|$ by Lemma 2. This reduces to $|x|=|x^R|$, which is true by assumption.

Therefore, we have proved the proposition.

2. Prove that $(w\bullet z)^R=z^R\bullet w^R$ for all strings $w$ and $z$.

Let $w$ and $z$ be arbitrary strings. Assume $(x\bullet z)^R=z^R\bullet x^R$ for every string $x$ such that $|x|<|w|$. There are two cases to consider:

If $w=\epsilon$, then $(\epsilon\bullet z)^R=z^R\bullet\epsilon=z^R$ by definition of $^R$ and Lemma 1, which also equals $z^R\bullet\epsilon^R=z^R\bullet\epsilon=z^R$ by definition of $^R$ and Lemma 1.

If $w=ax$ for some symbol $a$ and some string $x$, then $(ax\bullet z)^R=(a\bullet(x\bullet z))^R=(x\bullet z)^R\bullet a$ by Lemma 3 and definition of $^R$. We can also do $z^R\bullet(ax)^R=z^R\bullet x^R\bullet a$ by definition of $^R$, reducing the problem to $(x\bullet z)^R=z^R\bullet x^R$, which is true by assumption.

Therefore, we have proved the proposition.

3. Prove that $(w^R)^R=w$ for every string $w$.

Let $w$ be an arbitrary string. Assume $(x^R)^R=x$ for every string $x$ such that $|x|<|w|$. There are two cases to consider:

If $w=\epsilon$, then $(\epsilon^R)^R=\epsilon^R=\epsilon$ by definition of $^R$.

If $w=ax$ for some symbol $a$ and some string $x$, then $((ax)^R)^R=(x^R\bullet a)^R=a\bullet(x^R)^R$ by definition of $^R$ and Problem 2. We know $(x^R)^R$ is true by assumption.

Therefore, we have proved the proposition.

4. Give a formal recursive definition of $\#(a,w)$.
$$\#(a,w):=\begin{cases}
0 & \text{if $w=\epsilon$} \\
\#(a,x) & \text{if $w=bx$ for some symbol $b\neq a$ and some string $x$} \\
1 + \#(a,x) & \text{if $w=ax$ for some string $x$}
\end{cases}$$
5. Prove that $\#(a,w\bullet z)=\#(a,w)+\#(a,z)$ for all symbols $a$ and all strings $w$ and $z$.

Let $w$ be an arbitrary string and $a$ be an arbitrary symbol. Assume $\#(a,x\bullet z)=\#(a,x)+\#(a,z)$ for every string $x$ such that $|x|<|w|$. There are three cases to consider:

If $w=\epsilon$, then $\#(a,\epsilon\bullet z)=\#(a,z)$ and $\#(a,\epsilon)=0$ by the definition of $\#$. From there, we can show that $\#(a,z) = 0 + \#(a,z)$.

If $w=bx$ for some symbol $b\neq a$ and some string $x$, then $\#(a,bx\bullet z)=\#(a,x\bullet z)$ and $\#(a,bx)=\#(a,x)$ by definition of $\#$. We then have $\#(a,x\bullet z)=\#(a,x)+\#(a,z)$, which is true by assumption.

If $w=ax$ for some string $x$, then $\#(a,ax\bullet z)=1+\#(a,x\bullet z)$ and $\#(a,ax)=1+\#(a,x)$ by definition of $\#$. We then have $1+\#(a,x\bullet z)=1+\#(a,x)+\#(a,z)$, which is true by assumption after subtracting $1$ from both sides.

Therefore, we have proved the proposition.

6. Prove that $\#(a,w^R)=\#(a,w)$ for all symbols $a$ and all strings $w$.

Let $w$ be an arbitrary string and $a$ be an arbitrary symbol. Assume $\#(a,x^R)=\#(a,x)$ for every string $x$ such that $|x|<|w|$. There are three cases to consider:

If $w=\epsilon$, then $\#(a,\epsilon^R)=\#(a,\epsilon)=0$ by the definition of $\#$.

If $w=bx$ for some symbol $b\neq a$ and some string $x$, then $\#(a,(bx)^R)=\#(a,x^R\bullet b)$ and $\#(a,bx)=\#(a,x)$ by definition of $\#$. We then have $\#(a,x\bullet z)=\#(a,x)+\#(a,z)$, which is true by assumption.

If $w=ax$ for some string $x$, then $\#(a,ax\bullet z)=1+\#(a,x\bullet z)$ and $\#(a,ax)=1+\#(a,x)$ by definition of $\#$. We then have $1+\#(a,x\bullet z)=1+\#(a,x)+\#(a,z)$, which is true by assumption after subtracting $1$ from both sides.
