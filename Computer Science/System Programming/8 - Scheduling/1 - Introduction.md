In a busy system, there will be more processes running than CPU cores, so the OS has to decide which processes should be scheduled to run at any given cycle. It'll also have to choose processes that are running to pause so other processes can use their CPU. If we keep processes running too long, the computer will be unresponsive, but context-switching is expensive, meaning nothing will get done if the CPU swaps processes all the time. Having multi-threaded processes and multiple CPU cores only adds to the complexity.

Our scheduling will deal mainly with short term (CPU) scheduling, where we assume all processes are in memory and ready to go. A medium term scheduler deals with moving a process from paused in memory to paused on disk when there are too many processes or a process isn't using many CPU cycles. A long term scheduler gatekeeps processes requested by other processes to be executed, telling them yes, no, or wait.
