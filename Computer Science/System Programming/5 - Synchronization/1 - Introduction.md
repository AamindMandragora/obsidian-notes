Synchronization coordinates various threads so at critical sections, only one thread can access a resource at a time, which avoids race conditions. For example, when two threads increment the same global variable, they will have to do the addition locally, which means that they could either load the global variable and store the updated value one at a time, which is desired, or one will end up loading before the other one stores, which will end up overwriting one of the incrementations. To force the increment code to only be run one thread at a time, we need to make it mutually exclusive.
