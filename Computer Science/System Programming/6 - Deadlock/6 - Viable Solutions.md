If we make a naive arbitrator (mutex) that each philosopher must ask for permission to eat, then only one philosopher eats at a time and there's no deadlock or livelock. We can make this more efficient by giving the arbitrator all the chopsticks and, when a philosopher asks for theirs, lends them if able and takes them back after the philosopher finishes eating, letting multiple philosophers eat at the same time. However, this only works if the arbitrator is fair and all philosophers are good willed, as otherwise one philosopher could end up holding onto their chopsticks indefinitely and eat forever, which breaks deadlock and livelock but doesn't allow any of the other processes to continue.
# Leaving the Table (Stallings' Solution)

The original solution deadlocked because there were the same number of philosophers as chopsticks. However, if we repeatedly remove philosophers from the table until each one can be given two chopsticks at the same time, deadlock is impossible. 

In an actual system, we can do this using semaphores that let a certain number of philosophers through. If the philosophers aren't evil, then we have to switch contexts a lot, and we can't ever know the number of resources beforehand. Finally, semaphores obey system clocks and therefore end up adding the same processes back into the queue. If a philosopher becomes evil, there's nothing in place to stop them from eating as long as they want. This solution works best when timeouts or forced context switches ensure bounded wait.
# Partial Ordering (Dijkstra's Solution)

If we are able to number the chopsticks from $1$ through $n$, then we can modify the original solution by having each philosopher pick up their lower number chopstick instead of the one to their left. In this case, the situation where everyone picked up their left chopstick and deadlocked is impossible here as the last philosopher would attempt to pick up their right chopstick instead and fail, leaving one open chopstick for someone else to eventually pick up. Dijkstra broke `circular wait` which means deadlock is impossible. However, this is all dependent on the possibility that a numbering can be agreed upon, and still can enter livelock if each philosopher is perfectly in sync. If we introduce random sleeps and waits, the latter problem is fixed and the system is made fairer.
