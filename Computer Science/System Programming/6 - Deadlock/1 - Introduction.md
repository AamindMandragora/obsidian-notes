We will define a **system** as a set of rules by which a set of processes can move between states. where a state is either working or waiting for a particular resource. **Forward progress** is defined as, at any time, either a process is working or another that's waiting on a resource is able to obtain it. When forward progress is impossible, we call such a situation **deadlock**. Usually, for low-stakes systems, we can simply ignore deadlock and restart the system. However, there are many systems where that sort of solution isn't possible and we must formally prove that deadlock isn't impossible.
