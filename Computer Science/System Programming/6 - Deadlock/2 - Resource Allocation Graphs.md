We can model a system with a directed graph called a **resource allocation graph** (RAG), which draws arrows from resources to the processes using them and from processes to resources they're requesting. This effectively tracks which resource is held by which process and which process is waiting for which resource, and finding a cycle in the RAG means that the processes will deadlock. If all of the processes are forced to wait, then we'll say the system is deadlocked. Detecting deadlock then becomes as simple as running a DFS on the RAG, treating both processes and resources as nodes.
